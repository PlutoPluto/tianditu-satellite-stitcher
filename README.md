# tianditu-satellite-stitcher

> 纯前端（单 HTML 文件）的天地图卫星瓦片下载与拼接工具。无需后端、无需服务器中转下载，浏览器直连天地图、本地拼接出完整 JPEG。

## 特性

- **零后端**：单个 `index.html`，任意静态托管（GitHub Pages / VPS / 本地双击打开均可），无 Python/Node 运行环境依赖
- **Web Mercator 显示**：用 `img_w`（EPSG:3857）瓦片展示地图，高纬度地区比例不失真
- **框选下载**：默认拖动平移地图，点「框选范围」按钮后拖拽框选区域；也支持点击两个对角点
- **浏览器直连下载**：瓦片由浏览器 fetch 直连天地图（天地图已放行 CORS），不经服务器，Token 不出本机
- **多子域轮换重试**：自动在 t0–t7 子域间轮换，单块失败自动重试（3 次/瓦片 × 10 轮、20s 超时、8 并发、轮间 1–5s 退避）
- **防缓存空转**：`cache:'no-store'` + URL cache-buster，避免失败响应被浏览器缓存导致重试轮不发包
- **失败留白**：10 轮重试后仍有失败瓦片不再取消拼接，以白色填充后继续输出
- **分纬度拉伸拼接**：逐行按 `cos(纬度)` 拉伸（c 瓦片 EPSG:4490 投影），与 PIL 后端逻辑一致
- **JPG 输出**：与源瓦片格式一致，质量 0.95
- **角点信息**：输出四角经纬度 + 瓦片行列号（仅 WGS84，无 CGCS2000）
- **Token 自管**：天地图 Token 存浏览器 localStorage，全程不外传、不硬编码

## 使用方法

1. 用浏览器打开 `index.html`（或部署到 GitHub Pages）
2. 在左侧填入你的天地图 Token（于 [天地图控制台](http://lbs.tianditu.gov.cn/) 申请）
3. 选 zoom 级别，把地图拖到目标区域
4. 点「框选范围」→ 拖拽框选（松开确定），或直接点两个对角点
5. 点「开始下载拼接」，进度条实时显示下载 / 重试 / 退避倒计时 / 拼接状态
6. 完成后预览图 + 下载按钮，保存到本地

## 技术说明

| 项 | 说明 |
|---|---|
| 显示瓦片 | `img_w`（Web Mercator EPSG:3857），Leaflet 1.9.4 已内联进单文件 |
| 下载/拼接瓦片 | `img_c`（EPSG:4490 c-tiling） |
| 经纬度→瓦片 | `col=⌊(lon+180)/360·2^z⌋`、`row=⌊(90−lat)/360·2^z⌋` |
| 逐行拉伸 | `第 r 行高 = 256 / max(|cos(lat)|, 1e-6)`、其中 `lat=90−360·r/2^z` |
| 并发/超时 | 8 并发、单瓦片 20s 超时、3 次/子域重试、10 轮整体重试、轮间 1–5s 退避 |
| 防缓存 | `cache:'no-store'` + `&_cb=<时间戳>-<attempt>` |
| 输出 | Canvas → `toBlob('image/jpeg', 0.95)` → blob URL 下载 |

## 限制

- **Canvas 单边 ≤ 16000px**（浏览器画布硬限制）：超出时需缩小范围或降低 zoom
- **Token 需自备**：本工具不内置任何天地图 Token
- 瓦片能否下载取决于本机网络能否访问天地图
