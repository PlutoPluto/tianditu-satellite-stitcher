# 天地图卫星影像 下载拼接（静态版）

纯前端、单 HTML 文件的天地图卫星瓦片下载与拼接工具。浏览器直连天地图拉瓦片，本地 Canvas 拼成一张完整 JPEG —— 无后端、无中转服务器、Token 不出本机。

**在线使用**：<https://plutopluto.github.io/tianditu-satellite-stitcher/>
**本地使用**：下载 `index.html` 双击打开即可（`file://` 也行，无需起服务）

---

## 快速开始

1. 打开页面，首次进入填入天地图 Token
   （在 [天地图控制台](http://lbs.tianditu.gov.cn/) 申请，类型选**浏览器端**），Token 存在 `localStorage`，下次直接进地图
2. 拖动地图到目标区域，设置 zoom（1–18，默认 12）
3. 点「✥ 框选范围」在地图上拖框，或直接点两个对角点
4. 看「任务预估」确认瓦片数与输出尺寸，点「开始下载并拼接」
5. 完成后预览，点「下载完整 JPG」保存

地图右上角可勾选「叠加影像注记 (cia)」，任务数翻倍，注记叠在影像之上。

## 两个关键设计

**① 显示用 `w` 剖分，下载用 `c` 剖分**

| | 显示 | 下载 |
| --- | --- | --- |
| 图层 | `img_w` / `cia_w` | `img_c` / `cia_c` |
| 投影 | Web 墨卡托 EPSG:3857 | 等经纬 EPSG:4490 |

地图必须用 `w`，否则高纬度在屏幕上被压扁、框出的范围视觉上是错的；下载沿用 `c` 以与旧 Python+PIL 后端口径一致。两者靠经纬度对接。

**② 逐行按 `cos(纬度)` 拉伸**

```
第 r 行像素高 = floor( 256 / max(|cos(lat_r)|, 1e-6) )，  lat_r = 90 − 360·r/2^z
```

让每行内横纵像素代表相同地面距离，图像不失真。这是墨卡托纵向伸展的分段常数近似，zoom 越高越接近标准墨卡托。

> 所以输出图的宽高比**不等于**框选矩形，上下会被拉长，属正常现象。直接按 EPSG:3857 配准会有亚行级偏差，需要精确配准时用四角坐标做仿射纠正。

## 计算规则

```
n    = 2^zoom
col  = floor((lon + 180) / 360 · n)      row = floor((90 − lat) / 360 · n)

width  = cols × 256
height = Σ floor( 256 / max(|cos(lat_r)|, 1e-6) )
```

输出四角取**瓦片边界**（非选区边界），所以实际范围比选区略大，最多外扩不到一块瓦片 —— 写报告请用结果表里的坐标。坐标一律 WGS84，不做 CGCS2000 转换。

## 下载策略

8 并发 → 失败重排入队 → 轮间退避 → 最多 10 轮 → 拼接出图。

| 项 | 值 |
| --- | --- |
| 并发 / 超时 | 8 路并发，单请求 20 s（`AbortController`） |
| 子域轮换 | 首选 `(col+row)%8`，重试偏移 `+3`、`+6` 换 t0–t7 节点 |
| 重试 | 单片每轮 3 次，失败瓦片整体最多 10 轮，轮间退避 1–5 s（带倒计时） |
| 防缓存 | `cache:'no-store'` + URL 追加 `&_cb=<时间戳>-<attempt>` —— 否则失败响应被缓存，重试轮空转不发包 |
| 内容校验 | `content-type` 为 `image/*` 且 `size > 100 B`（cia 放宽到 `> 40 B`，空注记瓦片本身极小） |
| 解码 | `createImageBitmap`，异步不阻塞主线程 |
| 单瓦片最坏 | 3 × 10 = 30 次请求 |

**失败降级**：10 轮后仍有缺块也不取消任务，Canvas 铺白底逐块覆盖，缺失处留白；侧栏红色提示给出「N 块影像（白色填充）、M 块注记（该处无注记）」与累计请求次数。一张缺块的图比一张空图有用，且缺块一目了然。

**进度**：第一轮报全局进度；重试轮进度条从 0 重涨并显示本轮进度、待重下数与累计请求次数，退避时逐秒倒计时 —— 避免用户盯着不动的 99% 以为卡死。

## 输出

JPEG 质量 0.95，文件名 `tianditu_stitched_z{zoom}_{时间戳}.jpg`，`toBlob` → blob URL → `<a download>` 保存到本地。结果卡片给尺寸、失败瓦片数、网格、四角经纬度与瓦片行列号。

## 可调参数

集中在 `index.html` 约第 880 行的「常量与状态」区，改完刷新生效。

| 常量 | 默认 | 含义 |
| --- | --- | --- |
| `TILE_FETCH_CONCURRENCY` | 8 | 并发数，调大易被限流 |
| `TILE_RETRIES` | 3 | 单片单轮尝试次数 |
| `TILE_RETRY_ROUNDS` | 10 | 整体重试轮数 |
| `TILE_TIMEOUT_MS` | 20000 | 单请求超时 |
| `CANVAS_MAX_SIDE` | 16000 | Canvas 单边上限，勿改 |
| `CLICK_THRESHOLD_PX` | 5 | 拖动多少像素算画框（否则算单击选点） |

## 限制

- **Canvas 单边 ≤ 16000 px**（浏览器硬限制）。超限时预估面板警告并禁用开始按钮，请缩小范围或降低 zoom
- **Token 需自备**，免费 Key 有日配额，大范围高 zoom 很快吃满
- 整图在内存拼完才编码，瓦片上万时可能内存不足（会提示"图像编码失败"）
- 依赖本机能访问 `t0–t7.tianditu.gov.cn`，部分企业网络会拦掉个别子域
- 未做移动端适配，侧栏固定 392 px，按桌面端设计
